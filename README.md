# 文件批量重命名 · 便携版 v2.1.1

Windows 免安装的文件批量重命名工具。绿色版目录，零依赖，拷到任意 Windows 电脑上双击就能用。

- 适用系统：Windows 10 / 11（64 位，需 WebView2 运行时与系统自带的 .NET Framework 4.6.2 以上）
- 不需要安装 Python 或任何运行库
- 不写注册表、不装服务，配置保存在程序目录的 `FileRenamer.json` 里，删掉这个文件就恢复默认
- 界面用 WebView2 渲染，原生无边框窗口 + 深色 / 浅色主题

## 快速开始

1. 双击 `FileRenamer.exe`
2. 把文件 / 文件夹拖进窗口，或点「选择文件」「选择文件夹」「粘贴导入」（Ctrl+V 可直接粘贴资源管理器里复制的文件）
3. 导入的文件夹会作为一个节点保留，点它的名称逐层进入；点面包屑可返回上层
4. 每个模块打开时都自带一条默认规则（查找替换 / 插入内容 / 自动编号…），填参数就能用；一个模块要放多条时点分组右上角的「+ 添加××」；规则按从上到下的顺序依次执行
5. 右侧「新名称预览」列实时显示结果，确认后点「开始重命名」；想反悔点「撤回」

## 功能特性

### 13 条重命名规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 查找替换 | 按文本或正则表达式替换，支持 `\1` 反向引用 | `photo_001.jpg` → `image_001.jpg` |
| 批量替换 | 一次替换多组内容，或套用常见预设 | `(1).jpg` → `1.jpg` |
| 添加前后缀 | 在主名前后加内容，扩展名保持不动 | `file.txt` → `new_file_final.txt` |
| 提取子串 | 前 N 位 / 后 N 位 / 第 X 位起取 N 位 / 某字符前后 | `IMG_2026_001.jpg` → `2026_001` |
| 大小写转换 | 全小写 / 全大写 / 首字母大写 / 每词首字母大写 | `My File.TXT` → `my file.txt` |
| 智能序列号 | 起始值、步长、补零位数，可作前缀 / 后缀 / 替换整名 | `photo.jpg` → `001_photo.jpg` |
| 插入内容 | 在指定位置插入固定文本 / 序号 / 文件信息 | `note.txt` → `note_20260920.txt` |
| 模板替换 | 用 `{name}` `{ext}` `{ext_name}` `{n}` 拼新名 | `photo.jpg` → `photo-01.jpg` |
| 时间命名 | 按当前时间或文件修改/创建时间命名 | `doc.pdf` → `doc_20260920-1208.pdf` |
| 清理文件名 | 空格转下划线/连字符、删除空格、压缩空格、去特殊字符 | `my file#1.txt` → `my_file1.txt` |
| 删除字符 | 按位置区间、开头 N 个、末尾 N 个或指定字符删除 | `a-b-c.txt` → `abc.txt` |
| 扩展名处理 | 扩展名转小写/大写、替换成指定扩展名、删除扩展名 | `photo.JPEG` → `photo.jpg` |
| 智能去重 | 多个条目撞名时自动追加序号 | `a.txt`,`a.txt` → `a.txt`,`a_2.txt` |

规则可以自由组合，例如「清理文件名 → 小写 → 序列号」一条流水线处理相机导出的照片。
每条规则卡片右上角的开关可以临时停用，不用删掉重加。

每个模块第一次打开时就自带一条该模块的主规则（默认启用），不用再手动点添加；
一个模块下的次要规则仍按需点「+ 添加××」展开。手动删掉预置的那条之后不会被自动塞回来，
「清空已添加的规则」则会把每个模块恢复成各有一条默认规则的状态。

序号类型除了阿拉伯数字，还支持中文小写 / 大写、繁体、人民币大写、英文字母、罗马数字、带圈数字、全角数字。

「插入内容」的文件信息可以取：原文件名、主名、扩展名、所在文件夹、修改时间、创建时间、文件大小、图片尺寸，以及 EXIF 拍摄信息（相机品牌 / 型号 / 镜头 / 光圈 / 快门 / ISO / 焦距 / 拍摄时间）。

### 列表与预览

- 每行显示：勾选状态、原始名称、所在目录、新名称预览、类型、大小、修改时间、状态
- 状态用颜色区分：已完成（绿）、待处理（蓝）、未变更（灰）、失败（红）、重名（橙）
- 行内实时预览，改规则参数不用重新导入
- 文件夹作为目录节点保留，点名称逐层进入，面包屑可返回任意上层，不会在导入时递归展开
- 快捷键 `↑ ↓ / Home / End` 移动当前行，`空格` 勾选，双击行手动改名

### 执行与撤回

- **批量重命名**：先做冲突检测（同目录同名、目标已存在），有问题的条目会标红并跳过，不会误改
- **互换改名**：`a.txt → b.txt` 与 `b.txt → a.txt` 这类互相占用的情况会自动用两阶段改名处理
- **撤回**：点「撤回」按记录改回原名（后进先出，目录改名 / 仅改大小写也能正确还原）
- **移除**：只把条目从列表拿掉，不删除磁盘上的文件

### 其它

- 「复制」把选中项的完整路径或文件名复制为纯文本 / JSON（走系统剪贴板）
- 记住上次关闭时的窗口大小与位置，下次打开就是自己调好的那个尺寸（最大化状态下关闭也会记住）
- 深色 / 浅色主题（`Ctrl+T`），工作流面板可收起（`Ctrl+B`）
- 其余快捷键：`Ctrl+Z` 撤回、`Ctrl+A` 全选、`Ctrl+I` 反选、`Alt+↑` 返回上级、`F5` 重新读盘、`F1` 使用说明
- 快捷键：`Ctrl+O` 选择文件、`Ctrl+Shift+O` 选择文件夹、`Ctrl+V` 粘贴导入、`Ctrl+Enter` 开始重命名
- 右键行可以撤回、移除、复制路径
